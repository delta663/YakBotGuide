ตั้งค่า YakBot

เชิญบอท ตั้งสิทธิ์ในช่อง และเลือกระบบที่ต้องการใช้ในเซิร์ฟเวอร์ของคุณ

เชิญ YakBot เข้าเซิร์ฟเวอร์ ↗
เมนูหลักเริ่มต้นใช้งานคู่มือแต่ละระบบสิทธิ์และโควตาแก้ปัญหาติดต่อผู้ดูแลบอทเครดิต

เริ่มต้นใช้งาน

  1. กดปุ่มเชิญด้านบน เลือกเซิร์ฟเวอร์ที่คุณมีสิทธิ์จัดการ แล้วกดยืนยันใน Discord
  2. ในช่องโพสต์และช่องแจ้งเตือน ให้บอทมีสิทธิ์ View Channel, Send Messages, Embed Links และ Read Message History
  3. ใช้บัญชีเจ้าของเซิร์ฟเวอร์หรือ Administrator พิมพ์ /add-goldprices-post เลือกช่องโพสต์ ช่องแจ้งเตือน และสถานะการแจ้งเตือน จากนั้นเปิดช่องโพสต์เพื่อดูราคาทองครั้งแรก

อัตราแลกเปลี่ยน

ดูอัตราอ้างอิงของ 25 สกุลเงินเทียบกับบาท

  1. ใช้ /add-exchange-post เลือกช่องโพสต์
  2. ดูโพสต์ในช่องที่เลือก หรือใช้ /list-exchange-post เพื่อดู Post ID
  3. เมื่อต้องการย้ายช่อง ใช้ /update-exchange-post แล้วเลือก ID หากต้องการลบ ใช้ /remove-exchange-post
เปิดให้เซิร์ฟเวอร์ใหม่

  2. ดูโพสต์ในช่องที่เลือก หรือใช้ /list-oilprices-post เพื่อดู Post ID
  3. เมื่อต้องการย้ายช่อง ใช้ /update-oilprices-post แล้วเลือก ID หากต้องการลบ ใช้ /remove-oilprices-post
เปิดให้เซิร์ฟเวอร์ใหม่

  1. ใช้ /add-goldprices-post เลือกช่องโพสต์ ช่องแจ้งเตือน และเลือกว่าจะเปิดแจ้งเตือนหรือไม่
  2. ดูโพสต์ในช่องที่เลือก หรือใช้ /list-goldprices-post เพื่อดู Post ID
  3. เมื่อต้องการย้ายช่อง ใช้ /update-goldprices-post แล้วเลือก ID หากต้องการลบ ใช้ /remove-goldprices-post

ราคาทองฮั่วเซ่งเฮง

  1. ใช้ /add-goldhsh-post เลือกช่องโพสต์ ช่องแจ้งเตือน และเลือกว่าจะเปิดแจ้งเตือนหรือไม่
  2. ดูโพสต์ในช่องที่เลือก หรือใช้ /list-goldhsh-post เพื่อดู Post ID
  3. เมื่อต้องการย้ายช่อง ใช้ /update-goldhsh-post แล้วเลือก ID หากต้องการลบ ใช้ /remove-goldhsh-post

ตรวจเครือข่าย

ทดสอบการเชื่อมต่อจากฝั่งบอท

  1. ใช้ /network-check-ping สำหรับ ICMP หรือ /network-check-tcp แล้วระบุโฮสต์และพอร์ต เช่น 443
  2. ใช้ /network-check-http เพื่อตรวจ HTTP หรือ /network-check-web พร้อม URL เต็มเพื่อดูผล DNS, TCP, TLS และ HTTP ทีละขั้น
  3. อ่านผลในข้อความตอบกลับที่เห็นเฉพาะผู้สั่ง
ต้องขอเปิดเพิ่ม

มอนิเตอร์และแจ้งเตือน

ติดตามสถานะเว็บไซต์หรือโฮสต์ต่อเนื่อง และแจ้งเมื่อสถานะเปลี่ยน

  1. ใช้ /add-monitor-post เลือกช่องโพสต์ ช่องแจ้งเตือน และเปิดหรือพักการแจ้งเตือน
  2. เลือก /add-monitor-target-http, /add-monitor-target-tcp หรือ /add-monitor-target-icmp แล้วเลือก Post ID ในฟอร์ม กรอก Target ID ชื่อที่แสดง และปลายทาง บอทจะทดสอบก่อนบันทึก
  3. ใช้ /detail-monitor-post ดูผล หรือ /update-monitor-post ย้ายช่อง ใช้ /remove-monitor-target เพื่อลบปลายทางเดียว การใช้ /remove-monitor-post จะลบทั้งโพสต์และเป้าหมายภายใน
ต้องขอเปิดเพิ่ม

รายงานสถานะประจำวัน

ให้บอทส่งสถานะ เวลาทำงาน และความหน่วงไปยังช่องที่กำหนด

  1. ใช้ /configure-status-notification เลือกช่อง ใส่เวลาแบบ 24 ชั่วโมง เช่น 12:00 แล้วเปิด notification
  2. ตรวจรายงานในช่องที่เลือกเมื่อถึงเวลา ค่าเริ่มต้นใช้เวลาไทย หากต้องการย้ายช่อง เปลี่ยนเวลา หรือพักรายงาน ให้ใช้คำสั่งเดิม
ต้องขอเปิดเพิ่ม

ประกาศผู้เล่น

ส่งประกาศเตือน แบน หรือปลดแบนผู้เล่นให้สมาชิกในช่องเห็น

  1. ใช้ /configure-player-notice เลือกช่องประกาศ
  2. เปิด /player-notice เลือกประเภทประกาศ กรอกชื่อผู้เล่นและรายละเอียด แล้วส่งฟอร์ม
  3. ตรวจโพสต์ใหม่ในช่องประกาศ หากต้องการให้การแบนหรือปลดแบนมีผลในเกม ให้ดำเนินการในเกมด้วย

สิทธิ์และโควตา

เจ้าของเซิร์ฟเวอร์และ Administrator ใช้คำสั่งของระบบที่เซิร์ฟเวอร์ได้รับสิทธิ์ เซิร์ฟเวอร์ใหม่เปิดใช้อัตราแลกเปลี่ยน ราคาน้ำมัน และราคาทองสมาคมฯ

โควตาเริ่มต้นของระบบราคาคือประเภทละ 1 โพสต์ต่อเซิร์ฟเวอร์ เมื่อเปิดมอนิเตอร์จะสร้างได้ 3 โพสต์ แต่ละโพสต์เพิ่มได้สูงสุด 10 เป้าหมาย

แก้ปัญหา

ไม่เห็นคำสั่งในเมนู /

ตรวจสิทธิ์ Administrator และดูว่าระบบที่ต้องการต้องขอเปิดเพิ่มหรือไม่

บอทโพสต์ไม่ได้

ตรวจสิทธิ์บอทในช่องที่เลือกตามรายการเริ่มต้นใช้งาน รวมถึงสิทธิ์ที่กำหนดทับในระดับช่อง

สร้างโพสต์เพิ่มไม่ได้

ตรวจจำนวนโพสต์เดิมด้วยคำสั่ง list ของระบบ หากต้องการเพียงย้ายช่อง ให้ใช้คำสั่ง update แล้วเลือก Post ID เดิม

ติดต่อผู้ดูแลบอท

เมื่อขอเปิดระบบหรือเพิ่มโควตา ให้ส่ง Server ID ชื่อระบบ และจำนวนโพสต์ที่ต้องการ หากแจ้งปัญหา ให้แนบชื่อคำสั่งและข้อความตอบกลับที่เห็นใน Discord
