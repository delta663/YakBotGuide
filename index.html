ตรวจเครือข่าย มอนิเตอร์และแจ้งเตือน อัตราแลกเปลี่ยน ราคาน้ำมัน PTT ราคาทองสมาคมฯ ราคาทองฮั่วเซ่งเฮง ประกาศผู้เล่น
สิทธิ์และโควตา แก้ปัญหา ติดต่อผู้ดูแลบอท เครดิต

ตั้งค่า YakBot

เริ่มติดตามสถานะเว็บไซต์และโฮสต์ใน Discord ด้วยระบบ 4 มอนิเตอร์และแจ้งเตือน ซึ่งเปิดให้ทุกเซิร์ฟเวอร์ใหม่

เชิญ YakBot เข้าเซิร์ฟเวอร์ ↗

เริ่มต้นใช้งาน

  1. กดปุ่มเชิญ เลือกเซิร์ฟเวอร์ที่คุณดูแล แล้วยืนยันใน Discord
  2. ให้บอทมีสิทธิ์ View Channel, Send Messages, Embed Links และ Read Message History ในช่องโพสต์และช่องแจ้งเตือน
  3. ใช้บัญชีเจ้าของเซิร์ฟเวอร์หรือ Administrator เรียก /add-monitor-post เลือกช่องโพสต์ ช่องแจ้งเตือน และกำหนดว่าจะเปิดแจ้งเตือนหรือไม่
  4. ใช้ /add-monitor-target-http เลือก Post ID กรอกชื่อและ URL ของเว็บไซต์ เมื่อตรวจสำเร็จ ให้เปิดช่องโพสต์เพื่อดูสถานะ
