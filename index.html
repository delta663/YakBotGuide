ใช้คำสั่ง /guide ในเซิร์ฟเวอร์ Discord แล้วกดลิงก์ เพื่อดูคู่มือ YakBot สำหรับเซิร์ฟเวอร์ของคุณ

YakBot

บอท Discord สำหรับตรวจสอบเครือข่าย เฝ้าระวังสถานะเซิร์ฟเวอร์และเว็บไซต์ พร้อมแจ้งเตือนเมื่อสถานะเปลี่ยน

เริ่มต้นใช้งาน

เชิญบอทเข้าเซิร์ฟเวอร์

เชิญ YakBot เข้าเซิร์ฟเวอร์ ↗
  • กดปุ่มเชิญบอทด้านบน
  • เลือกเซิร์ฟเวอร์ที่คุณดูแล
  • กดยืนยัน

ให้บอทมีสิทธิ์ในช่อง

  • View Channel / ดูช่อง
  • Send Messages / ส่งข้อความ
  • Embed Links / ฝังลิงก์
  • Read Message History / อ่านประวัติข้อความ

ตั้งค่า YakBot ของคุณ

  • ใช้คำสั่ง /guide ในเซิร์ฟเวอร์ Discord ของคุณ ด้วยสิทธิ์ Owner / Administrator
  • กดลิงก์ เปิดคู่มือ YakBot ที่ได้รับจากบอท โดยลิงก์จะมีอายุ 1 ชั่วโมง
  • ดูการตั้งค่าของระบบต่างๆ ได้จากเมนู คู่มือระบบ
