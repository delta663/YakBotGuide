ตรวจเครือข่าย มอนิเตอร์และแจ้งเตือน อัตราแลกเปลี่ยน ราคาน้ำมัน PTT ราคาทองสมาคมฯ ราคาทองฮั่วเซ่งเฮง ประกาศผู้เล่น
แก้ปัญหา ติดต่อผู้ดูแลบอท เครดิต

ใช้คำสั่ง /guide ในเซิร์ฟเวอร์ Discord แล้วกดลิงก์ เพื่อดูคู่มือ YakBot สำหรับเซิร์ฟเวอร์ของคุณ

แก้ปัญหา

เลือกหัวข้อที่ตรงกับปัญหาเพื่อดูวิธีตรวจสอบและแก้ไขเบื้องต้น

การเปิดคู่มือ

เปิดคู่มือแล้วไม่เห็นเมนูระบบ

ใช้คำสั่ง /guide ในเซิร์ฟเวอร์ Discord ที่ต้องการ แล้วเปิดลิงก์ที่ได้รับจากบอท เมนูจะแสดงตามระบบที่เซิร์ฟเวอร์นั้นมีสิทธิ์และเปิดใช้งานอยู่ หากระบบที่ต้องการยังไม่ปรากฏ ให้ติดต่อผู้ดูแลบอทเพื่อตรวจสอบสิทธิ์

ลิงก์คู่มือหมดอายุหรือเปิดไม่ได้

ลิงก์คู่มือมีอายุ 1 ชั่วโมง ให้ใช้ /guide เพื่อขอลิงก์ใหม่ แล้วเปิดจากข้อความตอบกลับของบอทโดยตรง ตรวจว่าเบราว์เซอร์เปิดใช้งาน JavaScript หากลิงก์ใหม่ยังเปิดไม่ได้ ให้ติดต่อผู้ดูแลบอทพร้อมข้อความผิดพลาดที่แสดงบนหน้าเว็บ

คู่มือแสดงข้อมูลของเซิร์ฟเวอร์อื่น

ใช้ /guide ในเซิร์ฟเวอร์ที่ถูกต้อง แล้วเปิดลิงก์ใหม่ หากต้องการล้างเซิร์ฟเวอร์ที่เลือกไว้ ให้กดปุ่ม เปลี่ยนเซิร์ฟเวอร์ บนหน้าคู่มือก่อนเปิดลิงก์ใหม่

คำสั่งและสิทธิ์

ไม่เห็นคำสั่งในเมนู /

ใช้คำสั่งภายในเซิร์ฟเวอร์ที่มี YakBot และตรวจว่าคุณเป็นเจ้าของเซิร์ฟเวอร์หรือมีสิทธิ์ Administrator หากไม่เห็นคำสั่งของบางระบบ ให้ติดต่อผู้ดูแลบอทเพื่อตรวจว่าระบบนั้นเปิดใช้งานให้เซิร์ฟเวอร์แล้วหรือไม่

ขึ้นว่าเซิร์ฟเวอร์ไม่มีสิทธิ์ใช้งานระบบนี้

ติดต่อผู้ดูแลบอทพร้อม Server ID และชื่อระบบที่ต้องการใช้งาน เพื่อให้ตรวจสิทธิ์ของเซิร์ฟเวอร์ การให้สิทธิ์ Administrator กับผู้ใช้เพียงอย่างเดียวไม่ได้เปิดสิทธิ์ระบบเพิ่มเติมให้เซิร์ฟเวอร์

บอทปิดปรับปรุงหรือระบบถูกปิดใช้งาน

หากขึ้นว่า “บอทปิดปรับปรุงชั่วคราว” หรือ “ระบบนี้ถูกปิดใช้งานจากผู้พัฒนาระบบ” ให้รอประกาศหรือติดต่อผู้ดูแลบอทเพื่อตรวจสอบสถานะ

ขึ้นว่าให้รอสักครู่หรือมีคำสั่งทำงานอยู่

รอคำสั่งเดิมทำงานเสร็จแล้วจึงลองใหม่ หลีกเลี่ยงการส่งคำสั่งซ้ำติดกัน หากรอแล้วยังเกิดปัญหา ให้แจ้งชื่อคำสั่งและเวลาที่เกิดปัญหาแก่ผู้ดูแลบอท

ทำรายการไม่สำเร็จ แม้ตรวจสิทธิ์แล้ว

ตรวจสิทธิ์บอทในช่องที่ใช้งานตาม ขั้นตอนเริ่มต้นใช้งาน หากยังทำรายการไม่ได้ ให้ส่งชื่อคำสั่ง เวลาที่เกิดปัญหา และภาพข้อความผิดพลาดให้ผู้ดูแลบอทตรวจสอบ

โพสต์และมอนิเตอร์

บอทโพสต์ไม่ได้

ตรวจสิทธิ์ View Channel, Send Messages, Embed Links และ Read Message History ในช่องโพสต์ตาม ขั้นตอนเริ่มต้นใช้งาน รวมถึงสิทธิ์ที่กำหนดทับในระดับช่อง หากใช้ช่องแจ้งเตือนแยก ให้ตรวจสิทธิ์ดูช่อง ส่งข้อความ และฝังลิงก์ในช่องนั้นด้วย

สร้างโพสต์เพิ่มไม่ได้

ตรวจจำนวนโพสต์เดิมด้วยคำสั่ง list ของระบบ หากต้องการเพียงย้ายช่อง ให้ใช้คำสั่ง update แล้วเลือก Post ID เดิม หากถึงจำนวนโพสต์ที่ได้รับอนุญาต ให้ติดต่อผู้ดูแลบอทเพื่อตรวจสอบโควตา

เพิ่มรายการตรวจสอบไม่ได้

สร้างโพสต์ด้วย /add-monitor-post ก่อนเพิ่ม target แล้วเลือก Post ID ของโพสต์นั้น ตรวจข้อมูลในแบบฟอร์มให้ครบ โดย Port ต้องเป็นจำนวนเต็มระหว่าง 1 ถึง 65535

ไม่พบ Post ID

ตรวจรายการโพสต์ด้วยคำสั่ง list ของระบบที่ต้องการ และใช้คำสั่งในเซิร์ฟเวอร์ที่สร้างโพสต์นั้น ตรวจว่าเลือก Post ID ถูกต้องและโพสต์ยังไม่ได้ถูกลบ

แบบฟอร์มแจ้งให้เปิดใหม่

เรียกคำสั่งเพิ่มรายการตรวจสอบอีกครั้ง แล้วกรอกและส่งแบบฟอร์มที่เปิดขึ้นใหม่ หากยังพบปัญหา ให้แจ้งผู้ดูแลบอทพร้อมชื่อคำสั่งและภาพข้อความผิดพลาด

ยกเลิกโพสต์แล้ว แต่ข้อความยังอยู่ใน Discord

หากบอทแจ้งว่า “ยกเลิกโพสต์แล้ว แต่ลบข้อความใน Discord ไม่สำเร็จ” การยกเลิกโพสต์เสร็จแล้ว แต่ต้องให้แอดมินลบข้อความเดิมในช่องด้วยตนเอง

ยังแก้ปัญหาไม่ได้

ติดต่อผ่านหน้า ติดต่อผู้ดูแลบอท พร้อมข้อมูลต่อไปนี้เพื่อช่วยให้ตรวจสอบได้เร็วขึ้น

  • Server ID ของเซิร์ฟเวอร์ที่เกิดปัญหา
  • ชื่อคำสั่งและระบบที่ใช้งาน
  • ชื่อช่องหรือ Channel ID และ Post ID หากมี
  • วันและเวลาที่เกิดปัญหา
  • ภาพข้อความผิดพลาดและขั้นตอนที่ทำก่อนเกิดปัญหา
